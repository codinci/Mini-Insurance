# Mini Insurance Claims Management System

A backend-first portfolio project built with Spring Boot and PostgreSQL.

## Tech Stack

- Java 21
- Spring Boot 4
- Spring Security
- Spring Data JPA
- PostgreSQL
- Swagger / OpenAPI

## Running the project

1. Create PostgreSQL database `mini_insurance`
2. Configure credentials in `application.yml`
3. Run `InsuranceApplication`

## Swagger

http://localhost:8080/swagger-ui.html

## Current Features

- Project setup
- PostgreSQL connection
- Swagger documentation
- Health endpoint
